# Navnekonvensjoner

Denne referansesiden er ikke skrevet ennå.

Claude foreslår at denne siden bør dekke:

- Navnestandarder for kataloger, skjemaer og tabeller
    - Katalognavn kombinerer team, miljø og farge, for eksempel `eksempelteam_dev_green`
    - Hver katalog kommer med ferdige skjemaer for medallion-lagene
      (`bronze_default`, `silver_default`, `gold_default`)
    - Hver katalog lagrer data i sin egen S3-bøtte med egen kryptering
- Konvensjoner for kolonnenavn
- Navngivning av jobber, pipelines og notebooks
