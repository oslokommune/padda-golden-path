# Varsling og alarmer

Denne referansesiden er ikke skrevet ennå.

Claude foreslår at denne siden bør dekke:

- Tilgjengelige varslingskanaler: e-post via `email_notifications` i bundlen, Slack via
  en notification destination teamet selv setter opp (krever workspace-admin)
- Hva du kan varsle på: feilede jobber, kvalitetssjekker som feiler jobben, SQL alerts
- Plattformen har ingen ferdig oppsatt varsling; alt konfigureres av teamet
