# Målgrupper og forutsetninger

Plattformen er bygget for dem som jobber med data ved hjelp av kode.

## Hvem er plattformen for?

### Utviklere i dataproduktteam

Du bygger og vedlikeholder datapipelines og dataprodukter. Du koder i Python og/eller SQL, og har erfaring med dataflyter.

### Utviklere i analyseteam

Du henter inn, transformerer og tilgjengeliggjør data som grunnlag for analyse og rapportering. Du jobber tett på både kildesystemer og analytikere.

### Analytikere som koder

Du bruker SQL og/eller Python til å utforske data, bygge modeller og lage analyser. Du jobber i notebooks og trenger tilgang til kvalitetssikrede datasett.

---

## Hva trenger teamet ditt?

### Teknisk kompetanse

- **Python** — for mer avansert databehandling og pipelines
- **Git** — all kode versjoneres i GitHub
- Kan være fordelaktig med **SQL**-kompetanse for transformasjoner og spørringer (selv om assistenten [Genie](https://docs.databricks.com/aws/en/genie/) lar deg spørre i naturlig språk)

### Organisatorisk forankring

- En dataprodukteier som tar ansvar for dataproduktene over tid
- Avklart formål og hjemmel for dataene dere skal behandle
- Kapasitet til både utvikling og forvaltning — ikke bare førstegangsleveranse

### Data som egner seg

- Data fra fagsystemer eller fellessystemer som skal tilgjengeliggjøres
- Behov for transformasjon, kvalitetssikring eller sammenstilling
- Konsumenter som trenger dataene i Power BI, andre systemer eller analyser

---

!!! warning "Ikke en selvbetjent analyseplattform"
    Hvis du primært bruker Power BI, Excel eller Tableau uten å kode, er Fabric-plattformen riktig sted å starte. Data som er bygget på Databricks-plattformen kan likevel konsumeres derfra.
