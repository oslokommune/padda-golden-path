# Documentation templates (Diataxis)

Templates for the four documentation types in the [Diataxis framework](https://diataxis.fr/). Copy the one that fits and fill it in.

| File | Type | Use for |
|------|------|---------|
| `tutorial.md` | Tutorial | Guided learning experiences. Pages under **Kom i gang**. |
| `howto.md` | How-to | Task-oriented directions. Pages under **Guider**. |
| `explanation.md` | Explanation | Context, background, and "why?" answers. Pages under **Om plattformen**. |
| `reference.md` | Reference | Neutral fact descriptions. Pages under **Referanse**. |

Each template marks sections as **[OBLIGATORISK]** or **[FRIVILLIG]** and includes example content showing what belongs there. The info box at the top summarises the principles — delete it when you start writing.

For more context on how the four types relate to our documentation structure, see [`diataxis.md`](diataxis.md) in this directory.
