# Oppsett og arkitektur
**Lokalt**

- VS Code
- Databricks VS Code extension
- `uv` for Python-deps og wheels
- Eksempelprosjekt: `examples/vscode-demo`

**Remote (Databricks)**

- Workspace (notebooks, filer, jobs)
- Clusters / serverless compute
